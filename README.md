3. Preceding Question Prompting
This technique uses a sequence of questions to guide the AI's response from a broad topic to a more specific detail, building context along the way.

Prompt: "What is solar energy? Explain how it helps reduce reliance on fossil fuels."

Expected Output: "Solar energy is radiant light and heat from the Sun that is harnessed using various technologies. It helps reduce reliance on fossil fuels because it generates electricity without burning coal, oil, or natural gas, thereby providing a clean power source that doesn't deplete finite resources."

4. Missing Word Prompting
This technique provides an incomplete sentence and asks the AI to fill in the missing piece, which is useful for testing factual recall or generating specific terms.

Prompt: "Complete the sentence: Solar panels convert sunlight into electricity using semiconductor materials, most commonly ______."

Expected Output: "Solar panels convert sunlight into electricity using semiconductor materials, most commonly silicon."
